# Odoo agent gateway

Reserved for the Odoo.sh 19 addon that will implement atomic domain commands, approvals,
idempotency, events, policy checks, kill switches, and audit anchors.

This directory is intentionally not an installable addon in Phase 0. Phase 1 first proves
least-privilege read-only JSON-2 connectivity. The installable gateway begins in Phase 3 after its
security and integration tests exist.
